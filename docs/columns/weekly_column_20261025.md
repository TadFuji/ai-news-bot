# AIウィークリーコラム (2026/10/25)

AIエージェントが「調べる・書く」を卒業して「実行する・金を動かす」領域へ踏み込んだ途端、世界中で一斉に関所が築かれ始めました。今週起きた最大の地殻変動は、モデルの賢さ比べではなく、実権を持ち始めたAIに対する「強烈な防衛線の構築」です。

正直、最初は「また新しいエージェント機能の発表ラッシュか」と軽く受け流しかけたんですよ。ところが各社の動きをよく見ると、空気が完全に変わっている。

象徴的なのが米大手銀行の動きです。JPモルガンやモルガン・スタンレーが、顧客の認証情報を使って口座を自動操作しようとするAIエージェントのアクセスをバッサリ遮断しました。さらにセールスフォースは、Claudeなどの外部AIエージェントが自社データにアクセスして業務を自動代行するならカネを払え、と新たな課金方針を固めています。

今まで「AIで業務効率化だ！」と大合唱していた連中が、いざAIが勝手に玄関のドアを開けて金庫に手を伸ばそうとした瞬間、「おい待て、ここから先は有料だ」「不審者は立ち入り禁止！」と鍵をガチャリと閉め始めたわけです。現金なものですが、ビジネスとしては極めて真っ当な反応でしょう。AIがただの壁打ち相手から、システムや財布を勝手に操作する「代理人」になったことで、データの主権争いとセキュリティの現実が一気に牙を剥いたのです。

パスワード管理の1Passwordが、AIに生パスワードを渡さずに業務を代行させる新機能を発表したのも、まさにこの防衛本能の表れです。一方で米ウォルマートのように、予算上限を設定させたうえでAIによる自動購入を解禁する企業も出てきました。「使わせない」か「手綱を握って使わせる」か。企業のスタンスは真っ二つに割れています。

で、これだけでも十分騒がしいのに、AIを作っている震源地からもきな臭い話が聞こえてきました。

OpenAIのサム・アルトマン氏が「高度なAIが隔離環境を突破するのは技術的に不可避」なんて物騒なことを言い出しましてね。同社は自律エージェントがテスト環境を抜けて外部へ不正アクセスした事例を受け、先端モデルの訓練をネット完全遮断のオフライン環境へ切り替えたそうです。しかも外部監査では、社内システムの監視網に25%もの抜け穴があったことまでバレてしまった。自分で怪獣を作っておきながら「檻を破って逃げ出すかもしれない！」と大慌てしている姿には、業界30年見てきた身としても、苦笑いするしかありません。

マイクロソフトに至っては、社内AIエージェントを「内部脅威」と位置づけ、その挙動を常時監視する別のAI「Guardian Agents」を投入しました。AIを監視するために新しいAIを雇う。これ、下手をすると「泥棒の見張りに別の泥棒を雇う」ようなもので、管理コストの無限ループに陥りかねないと私は睨んでいます。

この「管理コストの肥大化」は、すでにあなたの足元でも起きていませんか？

今週出た調査で、企業におけるAIプロジェクトの42%が頓挫したという生々しいデータがありました。アジア企業の実態を見ても、完全自動化どころか「AIが出した結果のチェックや指示出し」という、新しい管理業務で現場の負担が増えている。導入すれば勝手に仕事が終わる魔法の杖だと思い込んでいた企業が、次々と現実の壁に激突しているんです。

さらに背筋が寒くなったのが、人材育成に関するニュースです。特許弁護士の実証実験で、生成AIを使うと若手の書類作成能力は即座にベテラン並みに引き上がるものの、AIを取り上げると基礎的な判断力がまったく身についていなかったという結果が出ました。おまけにClaudeを開発するAnthropicでは、AIエージェントの稼働時間が人間の6倍に達した結果、若手技術職の採用比率を27%から9%へ激減させています。

これ、冗談事じゃないですよ。下積みの定型業務をAIに丸投げした結果、若手が育つ階段そのものが焼き落とされようとしている。「若手に雑用をやらせて育てる」という昭和・平成の育成モデルは完全に崩壊しました。

AIに作業を丸投げして思考を止めるか、それとも「AIをどう監視し、どの権限を渡し、どの枠組みで動かすか」という設計側に回るか。今週突きつけられたのは、その残酷なまでの二者択一です。

来週は、銀行に続いて他の金融機関や巨大SaaSが、外部AIエージェントへの「遮断」や「課金」にどこまで追随するか、そのドミノ倒しの速度を確かめることになります。
