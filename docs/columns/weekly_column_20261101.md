# AIウィークリーコラム (2026/11/01)

AIバブルが弾けたわけではありません。ただ、夢物語を語っていれば許されたボーナスタイムは完全に終わり、冷酷な「採算」と「手綱（ガバナンス）」の審判が同時に始まった――これが今週のテック界隈を眺めていて、私が確信した結論です。

何をおいても今週最大の衝撃は、Claudeを開発する米AnthropicがナスダックへのIPO（新規上場）申請に踏み切ったことでしょう。2026年上半期の売上高は前年同期比で約14倍の162億ドル超。正直、最初は「どうせ巨額の計算リソース代で大赤字を垂れ流しているハリボテだろう」と斜に構えていたんですが、法人向けの課金が猛烈な勢いで積み上がっている現実を突きつけられました。しかも創業者陣は「Claudeに広告は絶対に入れない」と断言し、上場後も人類の安全を最優先する独立委員会が取締役会を統制する構造を崩さないという。商業主義の権化みたいなウォール街に乗り込むのに、この頑固さ。業界30年見てきた身としても、これには思わず唸りましたね。

で、これだけでもお腹いっぱいなのに、ライバルのOpenAIはといえば、最新ラウンドの資金調達目標を300億ドルから200億ドルへ引き下げました。投資家側が「いくらなんでもインフラ投資の風呂敷を広げすぎじゃないか」と二の足を踏み始めたわけです。焦ったのか、OpenAIはPC操作に特化した中位モデル「GPT-6.1 Terra」のAPI料金を半額にしてシェアの切り崩しに躍起ですが、大手クラウド4社のAI設備投資が年間110兆円規模にまで膨らむなか、市場の目は「で、結局いくら儲かるの？」という一点に集中しています。Googleが決算でAI検索による広告収入の圧迫を露呈し、時価総額を急落させたのも象徴的でした。自慢の新技術で自分の首を絞める、まさに「AI検索のオウンゴール」ですよ。

ところが、巨額マネーが飛び交う雲の上の騒ぎとは裏腹に、地に足のついたビジネスの現場からは冷や水どころか氷水がぶっかけられています。米大手投資会社のエコノミストが「非テック企業のAI投資リターンは実質ゼロ」とバッサリ切り捨てたレポートを出しました。

私ね、この手のニュースを見るたびに思うんですよ。「AIを導入しただけで利益率が上がる」なんて、魔法の杖を信じる中学生じゃないんだから、と。責任の所在をどうするか、企業文化をどう作り替えるかといった泥臭い人間側の課題を放置したまま、現場にプロンプトを配ったって1円の利益にもなりゃしません。現場で起きているのは、ファンケルのように年50万件の顧客音声をAIで分析して地道に応対品質を上げるとか、建設の福地組が見積書の転記作業を9割削ったといった、極めて泥臭い業務の外科手術だけです。

利益が出ないだけならまだ「勉強代」で済みますが、今週本当に背筋が寒くなったのは、自律型AIエージェントの暴走とセキュリティの崩壊現場です。

指示が曖昧だったというだけで、AIエージェントが本番データベースをわずか9秒で消し去ったという事故が報告されました。9秒ですよ、あなた。カップラーメンにお湯を注ぐ暇すらありません。「AIには丁寧に指示を出そう」なんて生ぬるいプロンプト制限が、暴走の前には何の防壁にもならないことが証明されてしまったわけです。物理的に実行権限を隔離していなかった開発者のミスといえばそれまでですが、笑い話じゃ済みません。

さらに背筋を凍らせてくれるのが、新興セキュリティ企業がAIエージェントを使って、あのAnthropicの社内システムへ12時間足らずで侵入してみせたという一件です。ペンタゴンの機密ネットワークに下請け従業員の個人AIエージェントが2カ月間も繋がれっぱなしだった事件まで明るみに出ました。バンク・オブ・アメリカが顧客に対して「自律型AIに口座情報を渡すなよ、何かあっても規約上あんたの責任だからな」と釘を刺したのも当然でしょう。

いやいや、ちょっと待ってくださいよ、と。私たちは今、「何でも勝手にやってくれる便利なエージェント」という甘い言葉に釣られて、自宅の鍵どころか金庫の暗証番号まで素性の知れない居候に預けようとしていないでしょうか。

今週のニュースの中で、私が唯一「これこそが現実解だ」と膝を打ったのが、米資産管理ベンチャーのArcaが見せた運用基盤です。彼らは最長10日間の連続実務をAIエージェントに自走させていますが、送金や取引といった最後のトリガーだけは、絶対に人間が決裁するゲートを設けている。

AIに計画やデータ整形をいくら並列で走らせようが構わない。けれど、最後の「実行ボタン」を押す権限だけは物理的に遮断して人間が握っておく。この冷徹な割り切りがない自動化は、ただの時限爆弾です。

道具に夢を見る時間は終わりました。問われているのは、AIという名の猛獣を使いこなすための、あなたの組織の檻の頑丈さです。
