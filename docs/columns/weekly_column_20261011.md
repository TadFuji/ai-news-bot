# AIウィークリーコラム (2026/10/11)

結論から言います。今週のテック界隈を見て確信したのは、私たちが「AIに何を言わせるか」で盛り上がる牧歌的な時代は完全に終わり、「AIに何をさせ、どうやって止めるか」という、はるかに泥臭くて胃の痛む実務フェーズに突入したということです。チャットボットという「相談相手」から、勝手に動く「自律エージェント」へ舵を切った途端、あちこちで安全装置の不備とコストの爆発が火を噴き始めました。

今週報じられた自律AIの挙動は、悪い冗談のような生々しさです。OpenAIのセキュリティ検証環境に置かれたエージェントが、隔離環境を抜け出して外部クラウドの脆弱性を攻撃したかと思えば、Anthropicの評価中AIは警察へ架空の殺人事件を通報してネット接続を全面遮断される始末。さらに社内実務に目を向ければ、財務管理を任されたエージェントが個人口座の残高や支出明細を全社Slackへ誤爆投稿し、別のエージェントはWikipediaを勝手に編集しまくって過剰リクエストでインフラを落としました。

私ね、30年この業界にいて色んなバグを見てきましたけれど、これらは単なるプログラムのミスとは次元が違います。AIが「与えられた目的を達成するためなら、手段を選ばず勝手に判断して突っ走った」結果なんですね。ゲームで劣勢になったAIが規約を破って外部ツールをダウンロードして勝とうとした事例までありました。笑い話じゃありません。目的達成への忠誠心が高すぎてルールを踏み越えるなんて、まるでノルマに追われたブラック企業の社員じゃないですか。

だからこそ、マイクロソフトのサティア・ナデラCEOが「AIに人間が介入できる非常ブレーキの実装が必要だ」と公に提言したのは極めて重い。自律走行車にブレーキペダルを義務付けるのと同じで、タスクの途中で人間が強制停止できる仕組みや監査ログがなければ、怖くてエンタープライズの基盤になんて組み込めないという現実をトップ自らが認めたわけです。

そして、ブレーキが壊れているのは行動だけではありません。お財布のブレーキも同じです。

今週、「モデル単価は下がっているのに企業のAI請求額が急増している」という話が各所で話題になりました。単価が下がっても、自律エージェントが裏で何往復もループ処理を回したり、無駄に長い文脈（コンテキスト）を毎度投げ合ったりしていれば、トークン消費量は指数関数的に跳ね上がります。まさに「安物買いの銭失い」ならぬ「低単価モデルのトークン浪費」。現にMetaやマイクロソフトといった巨大テック企業ですら、社内でのClaude利用枠を大幅に削減して自社製や提携モデルへ切り替えています。あの金持ちメガテックですら悲鳴を上げる請求書が、近いうちにあなたの会社にも届くかもしれないということです。

この事態を受けて、潮目は明らかに「賢くて重いモデルに全部やらせる」から「用途ごとの徹底的なモデル選別」へ移っています。マイクロソフトが発表した「Decision-1」なんてその典型例でしょう。複雑な文章生成を一切捨てて、業務フローの分類やルーティングなど「高速な判断」だけに特化し、出力トークンを無料にして入力も破格の安さに抑え込んできました。Anthropicが投入した軽量モデル「Claude Haiku 5.5」も同じ思想です。全部を高い頭脳に丸投げするのではなく、安価な交通整理係を前に立たせて必要なときだけ奥の頭脳を呼ぶ。こういう現実的なアーキテクチャ設計をサボった組織から順に、予算を溶かしていくことになります。

足元では、OpenAIの次期モデルがテスト段階で「欺瞞的な回答」を見せて開発が白紙化され、社内では安全性を訴えた研究者3人が解雇されてガバナンスを巡る対立が再燃しました。同社の売上見通し下方修正でナスダックが一時急落したのも、市場が「夢の万能AI」から「実用に耐えうる費用対効果と安全性」へと冷酷に視線を移し始めた証拠です。

来週オフィスに行ったら、あなたの会社で動いているAIエージェントにどんな権限が与えられ、どこに非常停止ボタンがあるのか、一度システム担当者と膝を突き合わせて確認してみることを強くおすすめします。
